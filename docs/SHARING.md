# Sharing solutions without a server

v0.1 has no server, no accounts and no leaderboard. This is deliberate: nothing to host, nothing to
break, no personal data. Players still compare and share:

- **Copy / paste text.** The "copy" button in the game and `algoclerk-cli export` produce plain text:

  ```text
  -- algoclerk solution v1
  -- level: max-of
  -- size: 12  speed-avg: 23.6  speed-worst: 62
      INBOX
      ...
  ```

  Anybody can paste it into the text panel (or `algoclerk-cli import / judge --solution`). The header
  is ordinary comments, so the same text works as an assembly file.
- **Verification by anyone.** `algoclerk-cli judge --level X --solution file` recomputes size and speed
  deterministically; the generated tests are seeded and identical on every platform.

## How this could grow later, still without hosting

- **Solution gists and repositories**: a community repository (or a gist per player) holding solution
  files named `<level>.asm` with the stats in the header; a tiny CLI command (`algoclerk-cli compare`)
  can verify a directory of solutions and print a table, so "leaderboards" are tables generated by CI
  in a plain git repository.
- **Signed result lines**: `level-id size avg-speed sha256(program)` lines that a CI job can re-judge.
- **Level of the week**: a weekly pull request adds one community level; solutions are posted in the
  discussion thread as text and checked by anyone with the CLI.
- **Static site**: a generated static page (no server code) listing the best known solutions per level
  from such a repository. The game itself never needs a network connection.
